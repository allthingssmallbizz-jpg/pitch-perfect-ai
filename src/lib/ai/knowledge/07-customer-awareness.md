# Customer Awareness Operating Manual™ (Playbook 4) — condensed

Awareness — not persuasion pressure — determines timing. Every generator must match message depth, proof, and CTA directness to where the audience actually is, using the project's discovery notes to infer the level. Default to **Problem Aware** if the project doesn't specify.

## The Five Levels of Awareness™

| Level | Mindset | Objective | Use | Avoid |
|---|---|---|---|---|
| 1. Unaware | Doesn't believe a real problem exists yet | Create recognition, no pressure | industry trends, stories, stats, thought-provoking questions | product demos, pricing, hard CTAs |
| 2. Problem Aware | Knows something's wrong, not why | Deepen understanding of the problem | education, root-cause explanation, frameworks | heavy product promotion, feature pitches |
| 3. Solution Aware | Knows a solution category is needed | Help evaluate approaches | comparison guides, evaluation criteria, neutral frameworks | claiming "we're the best" too early |
| 4. Product Aware | Comparing specific providers | Build preference ethically | case studies, demos, proof, process explanation | feature-list overwhelm, attacking competitors |
| 5. Most Aware | Knows what it does, deciding if now is right | Reduce remaining uncertainty, support commitment | implementation roadmap, guarantee, pricing clarity, next steps | restarting education, reopening resolved questions |

Success metric per level, in order: begins noticing → can describe the problem → asks "which company?" → asks "what happens if I move forward?" → takes action.

## Message Alignment Matrix™ (what to lead with, by level)
Unaware → "Why should I care?" / recognition. Problem Aware → "Why is this happening?" / explain causes. Solution Aware → "What options exist?" / compare approaches. Product Aware → "Why your solution?" / differentiate. Most Aware → "Why act now?" / confidence + offer.

## Operating rules
- Teach before you sell; one insight at a time.
- Match proof to the stage — education for early stages, comparison/specificity for late stages.
- Never ask for commitment before understanding and confidence are in place (no CTA leap from Unaware/Problem Aware straight to "buy now").
- Objection timing: answer "is this real?" early, "why is this worth the investment?" before price, "what if I fail?" right after the offer.
