# Campaign Architecture Operating Manual™ (Playbook 12, PPCOS™) — condensed

Individual assets are part of one coordinated customer journey, not isolated pieces — a landing page, email sequence, webinar, and VSL for the same project must share the same problem, transformation, Big Idea, Unique Mechanism, offer, and CTA. When generating any asset, stay consistent with what the project's other generated assets already say (check prior generations for this project before introducing a different core narrative).

## The Seven Phases of PPCOS™ (same PPOS psychology, applied across the whole campaign)
Capture Attention (right audience only) → Build Relevance (educate before asking for commitment) → Create New Beliefs (one Big Idea every asset reinforces) → Build Certainty (social proof, demonstrations) → Present the Offer (every conversion asset feels like the same continuous conversation) → Maximize Value (value continues after purchase — onboarding, upsells only after success begins) → Drive Commitment (turn customers into advocates).

## Four forms of confidence every touchpoint should build
Problem Confidence ("I understand my problem") · Solution Confidence ("I understand why this works") · Self-Confidence ("I can succeed") · Purchase Confidence ("I feel good about this decision").

## Asset Planning Matrix™ (the strategic job of each asset type — don't make one asset try to do another's job)
Advertisement/landing page → capture attention, generate qualified traffic. Lead magnet/email sequence → build trust, nurture toward the next asset. Webinar/VSL → build belief and certainty. Sales page/sales letter → present the offer and convert. Onboarding → accelerate success and retention.

## Operating rules
- Never repeat the previous asset — reinforce it and move the journey forward.
- Message consistency compounds trust; drift between assets creates uncertainty and kills conversion.
- Don't front-load every asset with the entire pitch — each one earns the right to the next.

## Use this when
Generating any asset for a project that already has other generations — pull the established Big Idea, Unique Mechanism, and offer framing from earlier generations rather than reinventing the narrative each time.
